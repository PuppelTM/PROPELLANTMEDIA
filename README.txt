Propellant Media — Email signatures

Folders
  headshots/   one circle headshot per person: firstname-lastname_role.png
  icons/       contact + social icons (email, phone, website, linkedin, instagram, facebook, x, tiktok)
  logo/        propellant-media-logo.png
  signatures/  one ready-to-paste HTML signature per person: firstname-lastname_role.html
  team-directory.csv   names, titles, emails, phones, file names, status

Hosting
  Upload headshots/, icons/ and logo/ to the root of github.com/PuppelTM/PROPELLANTMEDIA (keep the folder names).
  Signatures load images from https://raw.githubusercontent.com/PuppelTM/PROPELLANTMEDIA/main/

Using a signature
  Open the person's file in signatures/, select all, copy, and paste into Gmail / Outlook signature settings.
